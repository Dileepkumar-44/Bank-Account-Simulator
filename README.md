# Bank-Account-Simulator
A simple Python-based banking application demonstrating Object-Oriented Programming (OOP) concepts, including deposits, withdrawals, and balance management.

# Project Features
- Account Creation
- Initial Balance Setup
- Money Deposit
- Money Withdrawal
- Balance Enquiry
- Insufficient Balance Validation
- Positive Amount Validation
- Automatic Balance Updates
- Transaction Status Validation
- Object-Oriented Programming (OOP)
